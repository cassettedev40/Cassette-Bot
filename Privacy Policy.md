At Cassette, we respect and protect your privacy. This Privacy Policy explains how we collect, use, store, and safeguard information while you interact with the bot on Discord. By using Cassette, you agree to the terms outlined in this policy.


---

1. Data Collection

Cassette collects only the minimum data necessary to operate effectively and provide its features. The following information may be collected when you use the bot:

Discord Username and User ID: Used to identify users for interactions, AFK status, giveaways, and command execution.

Command Usage Data: Includes information about which commands are used (e.g., play, pause, skip, prefix, gstart) to ensure proper functionality.

Voice Channel Information: Temporarily used for music features such as join, leave, queue, and autoplay.

Publicly Available Information: Such as username, avatar, and server name, used for displaying information in bot commands (e.g., userinfo, serverinfo).


Cassette does not collect sensitive or private data such as passwords, emails, or direct message content.


---

2. How We Use Your Data

Collected data is used solely for the purpose of operating and improving Cassette’s features. Specifically:

To ensure core bot functionality, including music playback, giveaways, AFK systems, and server statistics.

To provide a personalized user experience, such as saving configurations and settings for your server.

To assist server administrators in managing bot settings (prefixes, profiles, configurations).

To analyze performance and usage patterns to maintain stability and improve user experience.


No data is ever sold, shared, or transferred to third parties for marketing or commercial purposes.


---

3. Data Retention

Cassette does not store user data indefinitely.

Temporary data (e.g., command execution or voice activity) is deleted once processing is complete.

Configuration and settings data (e.g., prefixes, user profiles) are stored only as long as they are needed for proper bot operation.

Users or server owners may request deletion or reset of configuration data at any time.

5. User Control and Data Access

Users have full control over how Cassette interacts with their data:

You may use commands to modify or delete certain data (for example, clearing AFK status or resetting a profile).

You may remove the bot from your server at any time to prevent further data collection.

Server administrators can adjust settings related to data usage and features.


Cassette does not store any private information that would require manual deletion requests.

We implement reasonable security measures to protect stored data against unauthorized access, misuse, or loss. However, no digital system is completely secure, and we cannot guarantee absolute protection. Users are encouraged to follow good security practices within Discord.
